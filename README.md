## 🚀 Overview

Codemate is an AI-powered code review tool that helps developers write better code. It leverages the **Gemini API** to analyze code, provide quality ratings, step-by-step explanations, and actionable improvement suggestions.

## 🌟 Features

* **Code Quality Rating** – Evaluates readability, maintainability, and purpose.
* **Actionable Suggestions** – Improve variable naming, add context, refactor, and optimize code.
* **Explanations** – Line-by-line breakdowns for clarity.
* **Modern Stack** – Built with **React, Tailwind CSS, and Node.js**.

## 🛠 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/manasaa01/CODEMATE---Ai-powered-code-reviewer.git
cd CODEMATE---Ai-powered-code-reviewer
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment

Create a `.env` file in the root directory and add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

### 4. Run the Application

```bash
npm start
```
